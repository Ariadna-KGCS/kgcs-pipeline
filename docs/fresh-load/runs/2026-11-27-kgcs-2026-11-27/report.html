Findings

What surfaced by looking closely

F1
a month of upstream growth and nothing else.
Against 2026-11-01: +15,416 Vulnerability, +17,797 Platform, +8,198 PlatformConfiguration, +616,406 MATCHES_PLATFORM, +14,593 EpssScore, +17,270 SsvcDecision, +40 KevEntry. Every layer whose source did not publish a new release is identical node for node in count: Weakness, Consequence, AttackPattern, the ATT&CK and ATLAS labels, D3FEND, CAR, SHIELD, ENGAGE, and all their relationship types.
F2
KEV: 1,805 of 1,805 entries attached, none dropped.
On 2026-11-01 one entry had no Vulnerability to hang from (CVE-2026-118527, in KEV since 2026-10-30). NVD published that CVE on 2026-11-03 and the entry is now loaded. 39 entries were added to the catalog since 2026-11-02; 39 + 1 = the +40.
F3
cwe_consequence_vocabulary FAIL, 3 violations, unchanged.
The same three CWE 5.0 impact values as on 2026-11-01 (DoS: Prevent Access in CWE-1260-C1 and CWE-1476-C1, Undefined Behavior in CWE-1335-C2). Loaded verbatim and flagged. The fix belongs to the spec vocabulary.
F4
one ADAPTED_FROM warning, known.
AML.T0073 Impersonation cites T1656, revoked in favour of T1684.001; the loader remapped it and kept the cited id on the edge. 44 edges, 39 distinct ATT&CK targets, 1 remap, as the offline expectation says.
F5
the relationship rate depends on what else the workstation is doing.
MATCHES_PLATFORM ran at 0.69 min per file while the machine was in interactive use (files 1 to 53 of 76) and at 0.42 once it was left alone (files 54 to 76; the unattended run earlier that morning held 0.47). One observation; the mechanism was not measured. The load is bounded by a single server thread, so it is sensitive to anything that slows that one core.
F6
BuildMetadata warns about uncommitted changes: a schema-mirror file, not loader code.
The tree was verified clean before the run. Step 0 then ran download_schemas.py, which refreshed data/schemas/CWE/cwe_schema_latest.xsd from the CWE 7.3 schema to 8.0. data/schemas/ is ignored, but five files of that mirror were still tracked, so the refresh showed up as a tracked change (the check ignores untracked files, so the run's own logs are not the cause). Nothing reads the mirror; the loader code is the one of 683f42b. The five files were untracked right after this run. The schemas archived with the 2026-11-01 build still carry the 7.3 schema: the mirror was not refreshed for that build.
F7
compare-v12 covers 8 of the 14 expected items.
The procedure runs it with --skip-cve, which leaves out the KEV, EPSS and SSVC totals. The full scan of step 1 took 0.8 min here, and its three totals were compared with the graph by hand (equal). Dropping --skip-cve in step 3 would make the gate do it; not changed in this run.
