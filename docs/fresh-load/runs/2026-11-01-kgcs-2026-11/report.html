Findings

What surfaced by looking closely

F1
CWE 5.0 moved the catalog namespace (cwe-7 → cwe-8).
load_cwe.py had the namespace hard-coded; it would have iterated zero Weakness elements and reported success with an empty CWE layer. Fixed in 803dc01 (namespace read from the root element; zero weaknesses now fails the step). Step 0's version diff is what caught it. CWE 5.0 also removes Category (422 → 0) in favour of Groupings/Dimensions (431/395) — not loaded today, spec-level decision.
F2
check_graph_quality FAIL PART_OF 441 vs 436 (expected file from September).
The October ATT&CK release adds 7 techniques and retires 2: +T1696 Anti-Automation Evasion (2 subs), T1697, T1698 Indirect Prompt Injection, T1699 Direct Prompt Injection, T1700 AI-Enabled Exfiltration (enterprise), T1476 (mobile), T1701 Command and Scripting Interpreter (ICS, 6 subs, replacing T0807 and T0853). 378 + 7 − 2 = 383; each new technique has one PART_OF → 436 + 5 = 441. technique_in_tactic and part_of_domain_coherence pass. Re-checked against expected-graph.json computed from today's raw (graph-quality.log).
F3
cwe_consequence_vocabulary FAIL, 3 violations.
CWE 5.0 introduces impact values the spec 1.2.1 vocabulary lacks: DoS: Prevent Access (CWE-1260-C1, CWE-1476-C1 — the latter a new weakness) and Undefined Behavior (CWE-1335-C2). Loaded verbatim as designed; SHACL and the Cypher check flag them. Fix belongs to the spec vocabulary (next release + pin bump).
F4
one ADAPTED_FROM warning, known.
AML.T0073 Impersonation cites T1656, revoked in the bundle (revoked-by → T1684.001, same name); the loader remapped and reported it. Same case as docs/spec-v1.2-deltas.md §"44, not 43".
F5
a second run_all_etl.py was alive during the first attempt.
A PowerShell pipeline whose Tee-Object failed to open its file left the python.exe running; it survived DROP/CREATE DATABASE (driver retries) and produced DeadlockDetected retries in the second attempt. Killed, database recreated, this run is single-process (0 deadlocks). Procedure updated: check Get-Process python* before launching and after cancelling.
F6
the cpe step took 71 min (≈45 in September)
for +4.7 % more MATCHES_PLATFORM. Not diagnosed (same instance hosts kgcs-v12 and kgcs-demo; no Bolt-level timing kept).
